# ICD-9-CM v32 (CMS)

File deskripsi resmi kode ICD-9-CM versi 32 (FY2015, versi terakhir sebelum AS beralih ke ICD-10).
Diunduh 2026-11-18 dari:
https://www.cms.gov/Medicare/Coding/ICD9ProviderDiagnosticCodes/Downloads/ICD-9-CM-v32-master-descriptions.zip

- `CMS32_DESC_LONG_SG.txt`  : 3.882 kode prosedur (Volume 3), deskripsi panjang
- `CMS32_DESC_SHORT_SG.txt` : kode prosedur, deskripsi pendek
- `CMS32_DESC_*_DX.txt`     : kode diagnosis ICD-9-CM (tidak dipakai; diagnosis memakai ICD-10)

Catatan: Indonesia memakai ICD-9-CM edisi 2010 dan modifikasi lokal (IM). Kode v32 dipakai sebagai
pendekatan sampai daftar resmi versi Indonesia tersedia.
