Peta Graf Tarif

Semua node di graf pilot dalam satu gambar. Setiap lingkaran adalah satu kategori: titik biru di belahan kiri berasal dari Perbup Cianjur, titik oranye di belahan kanan dari Perbup Rembang. Garis hijau tua (SAMA_DENGAN) menghubungkan layanan yang sama di kedua dokumen. Golongan Rembang ada di kolom kanan. Geser untuk berpindah, gulir atau cubit untuk memperbesar, klik node untuk melihat tetangganya.

Klik sebuah node

Harga layanan dan golongan muncul saat kursor diarahkan ke node, dan tabel lengkapnya muncul di sini setelah node diklik. Node besar adalah penghubung: kategori, golongan, dokumen (Perbup), dan rumah sakit. Titik kecil adalah layanan. Biru dari Perbup Cianjur, oranye dari Perbup Rembang.

Edge TARIF ganda (satu per kelas) digambar sebagai satu garis, begitu juga TARIF_GOLONGAN (49 edge, 9 garis). Jumlah di kotak centang adalah jumlah edge di graf. Posisi node disusun per kategori, bukan hasil simulasi gaya, supaya kelompoknya terbaca. Data dari out/graf_pilot.graphml.
